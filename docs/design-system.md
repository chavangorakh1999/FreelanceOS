# Design system: Coral (Hallmark redesign)

The app was redesigned with the [Hallmark](https://github.com/Nutlope/hallmark) skill (installed in `.claude/skills/hallmark`, theme **Coral**, app-screen scope, full depth).
Warm paper and cotton stationery instead of cool grey; General Sans with Geist Mono for figures; letterpress controls.

Tokens live in `apps/web/src/app/tokens.css` (Coral, generated by `theme.mjs scaffold`) and `base.css`. `globals.css` maps the app's semantic names
(`shell`, `panel`, `card`, `stat`, `line`, `accent`, status tints) onto them, so every screen takes the system from one place.

| Role | Token | Use |
|---|---|---|
| page / sidebar / sheet | `paper`, `paper-2`, `cotton` (`panel`, `shell`, `card`) | ground, sidebar, cards |
| text | `ink`, `ink-2`, `muted` | all at least 4.5:1 on their surfaces |
| primary action | `board` (ink) with `board-type` | the one filled button per view (`.btn-ink`) |
| secondary action | cotton stock with a lit top edge (`.btn-card`) | letterpress card |
| accent | `accent` = deep coral | links, focus, selection, progress; never a fill behind text |
| signature | `.pressed` in `paid` | settled records (paid, signed, accepted) are pressed into the page in ink, not badged |
| figures | `.fig` (Geist Mono, tabular) | money columns, ledger values, stat figures |

Rules the Floor enforces (checked with `node .claude/skills/hallmark/scripts/sloplint.mjs apps/web/src --scope app`):
no literal colours past the tokens, no dashes in copy, no middle-dot meta strings, no decorative status dots (timelines use a 3px rule),
no emoji icons, focus-visible everywhere, reduced-motion fallback.

The client portal uses the same system, mobile first.
